# docs/ — 一時メモ置き場

このディレクトリは、調査メモ・移行計画・作業ログなどの**一時的なメモ**を
置くための場所です。内容は古くなっていたり不完全だったりする可能性があり、
恒久ドキュメントとしての管理・保守は行いません。

現在の設定や運用方法を参照したい場合は、以下を参照してください：

- リポジトリ概要: ルートの `README.md` / `README.ja.md`
- ホスト固有の情報: `hosts/*/README.md`
- モジュールの情報: `nixos/*/README.md`、`home/*/README.md`
- 運用ルール: `AGENTS.md`
