# Encrypted Secrets (`secrets/`)

Agenix-rekey secrets encrypted with age. Secrets are stored in master definition files encrypted for the offline master identity, and rekeyed per host for distribution and pure Flake evaluations. Never commit plaintext secrets to version control.

## Directory Structure

```text
secrets/
├── master/                          # Master-encrypted secrets (offline Bitwarden recipient)
│   ├── common/                      # Fleet-wide secrets (deploy_key.age)
│   ├── hosts/<hostname>/            # Host-specific secrets (password hashes, nebula_key.age, emergency_ssh_token.age)
│   └── services/<service>/          # Service-specific secrets (backup, ddns, discord-bridge, signing, conoha-vps-mcp)
├── rekeyed/                         # Age files generated by agenix-rekey (committed to Git)
│   ├── home/<hostname>/<username>/  # home-manager secrets (decrypted with the user SSH key)
│   └── hosts/<hostname>/            # NixOS host secrets (decrypted with the host SSH key)
└── migration-manifest.json          # SOPS to agenix-rekey inventory manifest
```

| Directory / File | Scope | Description |
| :--- | :--- | :--- |
| `master/common/` | Fleet-wide | Secrets shared across all machines (deploy key for `nix-config-private`). |
| `master/hosts/<hostname>/` | Host-specific | User password hashes, root password hash, Nebula private keys, emergency tokens. |
| `master/services/<service>/` | Service-specific | Service secrets (Cloudflare DDNS, Restic, Discord bridge, commit signing, ConoHa API). |
| `rekeyed/hosts/<hostname>/` | Host-specific | Auto-generated `<hash>-<name>.age` files encrypted for the target host SSH key. Tracked in Git for offline and CI builds. |
| `rekeyed/home/<hostname>/<username>/` | Host & user | Auto-generated `<hash>-<name>.age` files encrypted for the user SSH key used by home-manager. Tracked in Git. |
| [migration-manifest.json](migration-manifest.json) | Fleet-wide | Migration rules mapping legacy SOPS keys to agenix master targets. |

The `master/` and `rekeyed/` trees are created by `just secret-migrate` and `just secret-rekey`; the legacy SOPS YAML files remain until migration is complete.

Plaintext files and runtime credentials outside `secrets/`:
- Nebula root CA certificate: `nixos/networking/nebula/ca.crt` (public, unencrypted).
- Nebula node certificates: `hosts/<hostname>/nebula.crt` (public, unencrypted).
- Minecraft forwarding secret and RCON password: generated on `shosoin-tan` at service start with `openssl rand`.

## Defense in Depth and Key Model

Access control uses four distinct layers:

| Layer | Environment | Storage / Mechanism | Purpose |
| :--- | :--- | :--- | :--- |
| Layer 1: Bitwarden Vault | Bitwarden (`nix-config/`) | Secure Notes & SSH Keys | Offline isolation of `agenix-master-key`, `nebula-ca/ca.key`, and workstation SSH keys (`ssh/<hostname>`). |
| Layer 2: Ephemeral RAM | Workstation (`/run/user/<uid>/agenix/`) | tmpfs mode 0600 & exit trap | Ephemeral identity storage during operator commands. Discarded immediately on exit. |
| Layer 3: agenix-rekey | Git repository (`secrets/master/`) | Nix module dependency resolution | Resolves host bindings and rekeys master secrets per target host. |
| Layer 4: Target Runtime | Fleet machines (`/run/agenix/`) | SSH host key (`/etc/ssh/ssh_host_ed25519_key`) or user SSH key (`~/.ssh/id_ed25519`) | Decrypts only the host's `secrets/rekeyed/hosts/<hostname>/*.age` files and the user's `secrets/rekeyed/home/<hostname>/<username>/*.age` files. |

### Bitwarden Vault Layout

- `nix-config/agenix-master-key` (Secure Note): Primary age secret key (`AGE-SECRET-KEY-1...`).
- `nix-config/nebula-ca/ca.key` (Secure Note): Disaster recovery backup of the offline Nebula root CA private key.
- `nix-config/ssh/<hostname>` (SSH Key): User workstation SSH keys (`id_ed25519`).

## Common Workflows

Commands use [justfile](../justfile) recipes backed by [scripts/secret.ysh](../scripts/secret.ysh):

### Rekey Host Secrets

Rekey after changing `age.rekey.hostPubkey` or modifying master secrets:

```bash
just secret-rekey
```

### Edit a Master Secret

Decrypts with the Bitwarden master identity in tmpfs, opens the editor, and wipes the key on exit:

```bash
just secret-edit secrets/master/services/ddns/cloudflare_api.env.age
```

### Import Staged Secrets

Stage plaintext into `.secrets-staging/` matching the `secrets/master/` layout, then encrypt and rekey:

```bash
# Stage plaintext
mkdir -p .secrets-staging/hosts/<hostname>
echo -n "$SECRET" > .secrets-staging/hosts/<hostname>/user_password_hash

# Preview plan
ysh scripts/secret.ysh apply-staging --dry-run

# Encrypt, shred plaintext, and rekey
just secret-apply-staging
```

### Migrate from SOPS

Migrate legacy SOPS keys into agenix master files according to [migration-manifest.json](migration-manifest.json):

```bash
just secret-migrate
```

### Diagnostics

Run tool, manifest, and environment health checks:

```bash
ysh scripts/secret.ysh doctor
```
