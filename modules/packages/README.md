# System Packages

Pre-defined groups of system-level packages that can be enabled or disabled via options.

## Categories

- **`base.nix`**: Core essentials (git, vim, etc.) required for basic system administration.
- **`monitoring.nix`**: System monitoring tools (btop, fastfetch, etc.) and hardware-specific tools.
- **`network-tools.nix`**: Network diagnostic and utility tools (curl, nmap, gping, etc.).
- **`data.nix`**: Data processing and compression tools (jq, unzip, etc.).
- **`nix-tools.nix`**: Nix-specific development and management tools.
- **`security.nix`**: Security-related tools and hardening settings.
- **`default.nix`**: Definition of all `my.packages.*` options.
