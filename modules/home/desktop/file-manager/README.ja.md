# File Manager Module (Thunar)

本モジュールは、Niri デスクトップ環境の標準ファイルマネージャーとして **Thunar** を設定します。

## 設計思想 / Nautilusからの移行理由

以前は Nautilus を使用していましたが、GNOME 依存が強く、軽量な Wayland コンポジタ (Niri) ベースの環境ではリソース面・カスタマイズ面で最適ではない部分がありました。

Phase 7 にて、より軽量でカスタマイズ性が高い **Thunar (Xfce)** に完全に移行しました。

## 機能統合とカスタマイズ

Thunar をスタンドアロン（非 Xfce 環境）で快適に使用するため、以下のシステムサービスと組み合わせています（これらは `niri.nix` などのシステムレベルで有効化されています）。

- **gvfs**: ゴミ箱のサポート、および USB メモリ等の外付けドライブの自動マウントと表示。
- **tumbler**: 画像や動画のサムネイル生成・表示。
- **xfconf**: デスクトップ環境非依存での設定の永続化。

### カスタム設定
- **プライバシー保護**: `Recent Files` (最近使ったファイル) の履歴保存・表示は `xfconf` を通じて明示的に無効化されています。
- **利便性**: `thunar-archive-plugin` を追加し、右クリックから直接アーカイブの作成・展開が可能です。
