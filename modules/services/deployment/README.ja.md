# Deployment Module (comin)

本モジュールは、コミュニティ標準のデプロイツールである `comin` を使用して、全ホストの自動アップデートを管理します。

## 設計思想

これまでは `torii-chan` 上で動作する中央集権型の Update Hub サーバーが各クライアントに更新を指示する構成を取っていましたが、Phase 7 にて **Pull-based (分散型)** アーキテクチャに移行しました。

- **中央サーバー不要**: 各ノード（ホスト）が独立して自身の構成を最新に保ちます。
- **セキュリティ向上**: リモートからコマンドを実行されるリスクが排除され、より安全なプロビジョニングが可能になっています。
- **安定性**: コミュニティ製の枯れたツールを利用することで、運用コストが下がりました。

## 仕様

- **ポーリング間隔**: 5分おき (300秒)
- **対象ブランチ**: `main`
- **動作**: リポジトリの最新の `main` ブランチに更新があれば、自動的に `nixos-rebuild switch` を実行して状態を同期させます。
