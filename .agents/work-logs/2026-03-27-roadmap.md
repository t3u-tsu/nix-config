## 【PHASE A】クリティカル改善（今週中）

**目標**: 依存度削減、基本性能確保

### A-1: Noctalia 依存度削減

**問題**: 
- media key や screenshot が全て Noctalia IPC に依存
- Noctalia 起動失敗時にこれらが動作しない

**解決方法**:
- Niri native のキーバインド併用設定
- Noctalia 起動失敗時の fallback 用意
- 工数: 2-3h（キーバインド調整、テスト）

**実装内容**:
- `modules/home/desktop/niri/default.nix` 更新
  - 既存: `XF86AudioRaiseVolume` → `noctalia-shell ipc call volume increase`
  - 新規: fallback として Niri native command も追加
- fallback keybinds セクション新設

**成果物**:
- `modules/home/desktop/niri/default.nix` (keybinds 拡張)
- `.agents/work-logs/2026-03-28-noctalia-fallback.md`

**テスト方法**:
```bash
# Noctalia サービスを停止
systemctl --user stop noctalia-shell

# media key（e.g., Volume Up）が Niri native で反応するか確認
# → fallback keybind で動作することを確認
```

### A-2: Browser 拡張機能の精選

**問題**: 
- 20+ の拡張機能 → 起動遅延、メモリ使用量増加
- 不要な拡張機能が多い

**現在のリスト分析**:

**必須（常時有効）:**
- uBlock Origin: 広告ブロック
- Bitwarden: パスワード管理
- SponsorBlock: YouTube スポンサー部分スキップ

**オプション（disable 可能）:**
- Keepa: Amazon 価格追跡
- Tampermonkey: ユーザースクリプト
- Wappalyzer: 技術スタック検出
- Video DownloadHelper: 動画DL

**削除候補**:
- Dark Reader: Dracula theme で不要
- YouTube NonStop: 不要機能
- LINE: Browser 版未使用

**戦略**:
- `modules/home/desktop/browsers.nix` で enable フラグ分離
- 必須拡張: `cfg.extensions.essential = true` (デフォルト有効)
- オプション拡張: `cfg.extensions.optional.enable = false` (デフォルト無効)
- 削除拡張: ポリシーから除去

**実装内容**:
```nix
# Before: すべて force_installed
ExtensionSettings = {
  "uBlock0@raymondhill.net" = { ... };
  "keepa.com" = { ... };
  ...
}

# After: 分類
# Essential
"uBlock0@raymondhill.net" = { installation_mode = "force_installed"; };
# Optional
"keepa.com" = {
  installation_mode = mkIf cfg.extensions.optional.enable "force_installed";
};
```

**測定方法**:
```bash
# 起動前後でメモリ・CPU を測定
top -p $(pidof firefox)
# または
/usr/bin/time -v firefox
```

**成果物**:
- `modules/home/desktop/browsers.nix` (拡張機能分離)
- `.agents/work-logs/2026-03-29-browser-optimization.md` (測定結果含む)

### B-4: Troubleshooting Guide 作成

**ファイル**: `modules/home/desktop/TROUBLESHOOTING.md`

**内容例**:

```markdown
# トラブルシューティングガイド

## キーバインドが反応しない

### 症状
`Mod+Return` を押しても Alacritty が起動しない

### 原因の確認

1. Niri が起動しているか確認
```bash
systemctl --user status niri
```

2. Noctalia IPC に依存するキー（Volume等）か確認
   - YES → A-1 の fallback を確認
   - NO → 以下へ

3. キーボード入力を確認
```bash
sudo evtest
# Mod キーが認識されているか確認
```

### 解決方法

1. Niri を再起動
```bash
systemctl --user restart niri
```

2. Noctalia が起動失敗していないか確認
```bash
systemctl --user status noctalia-shell
journalctl --user -u noctalia-shell -n 20
```

3. Niri 設定の構文エラー確認
```bash
nix flake check
```

---

## 起動が遅い

### 診断方法

1. 起動時間測定
```bash
time niri
```

2. 拡張機能が多すぎないか（Browser）
   - 拡張機能削減後に再測定 → A-2 参照

3. ロード中のサービス確認
```bash
systemd-analyze
systemctl --user list-units --state=running
```

---

## Noctalia が起動しない

### ログ確認
```bash
journalctl --user -u noctalia-shell -n 50
```

### フォールバック使用
- Noctalia IPC コマンド（Volume, Screenshot等）は Niri native で動作
- see: KEYBINDS.md の「フォールバック」列
```
