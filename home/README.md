# Home Modules

User-specific configurations managed via Home Manager.

## Modules

- **`cli-tools.nix`**: Essential CLI utilities (fzf, zoxide, ripgrep, yazi, zellij).
- **`starship.nix`**: Prompt configuration for shell styling.
- **`shell.nix`**: Zsh shell setup, options, and plugins.
- **`git.nix`**: Git user settings and global configuration.
- **`ssh.nix`**: SSH configuration and client options.
- **`atuin.nix`**: Shell history management and synchronization.
- **`desktop/`**: User-specific desktop environment configuration (browsers, wm, themes).
- **`default.nix`**: Imports all base home modules.
