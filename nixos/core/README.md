# Core Modules (`nixos/core/`)

Core operating system localization and console configuration.

## Modules

| File | Description | Option |
| :--- | :--- | :--- |
| `i18n.nix` | Locale (`ja_JP.UTF-8`, `en_US.UTF-8`) and console keymap configuration (`us`). | `my.core.i18n.enable` (Default: `true`) |
| `default.nix` | Core module aggregator. | — |
